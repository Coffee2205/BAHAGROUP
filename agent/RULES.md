# WORKING RULES & SAFETY PROTOCOLS

## 1. Quy tắc UI/UX
- Giao diện 100% tiếng Việt, thân thiện với người dùng lớn tuổi (chủ cửa hàng ~45 tuổi).
- TUYỆT ĐỐI không hiển thị các thuật ngữ kỹ thuật phức tạp như CPC, CPM, CTR mà không có chú thích đơn giản.

## 2. Quy tắc an toàn tài chính & Bảo mật
- KHÔNG gọi API thanh toán thật hoặc kích hoạt chiến dịch quảng cáo trả phí thật khi chưa có phê duyệt.
- KHÔNG đưa Bot Token, API Key hoặc thông tin nhạy cảm lên kho mã nguồn công cộng. Phải dùng biến môi trường hoặc file cấu hình mẫu (`config.example.js`).

## 3. Quy chuẩn tính năng bắt buộc
- Tích hợp Telegram Bot API phải gửi được tin nhắn THẬT (tên chiến dịch, ngân sách, thời gian, trạng thái) về nhóm hoặc tài khoản khi người dùng bấm xác nhận.
